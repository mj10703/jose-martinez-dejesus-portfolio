Page structure

Every page needs <!DOCTYPE html>, an <html> element, a <head> for settings like the title, and a <body> for everything visitors see.

Semantic elements

Elements like <header>, <nav>, <main>, <section>, and <footer> describe what each part of the page is for, which helps screen readers and search engines.

Links and images

The <a href> element creates links. Images use <img src alt>, and the alt text describes the image for people who cannot see it.

Linking a stylesheet

An external stylesheet is connected with a <link rel="stylesheet"> tag in the <head>. One file can style every page on the site.

The box model

Every element is a box made of content, padding, border, and margin. Padding is space inside the border and margin is space outside it.

Variables and themes

CSS variables such as --bg store a value once and reuse it with var(--bg). Changing the variables is how this site switches between light and dark mode.

Flexbox

display: flex lines up items in a row and lets them wrap, space out, or center. The navigation bar on this site uses it.

Variables: let and const

Use const for values that will not be reassigned and let for values that will change.

Functions

A function groups steps under a name so they can be reused. It runs when it is called, or when an event such as a click triggers it.

Selecting elements

document.querySelector() finds an element using a CSS selector like #greet-button. Giving buttons an id makes them easy to select.

Click events

addEventListener("click", function) tells the browser to run a function every time that element is clicked.

If statements

An if statement runs code only when a condition is true, and else handles the other case. The greeting uses one to check for an empty name.

Changing page content

Setting element.textContent replaces the text inside an element, which is how JavaScript updates the page without reloading it.

Commits

git add stages changes and git commit saves a snapshot with a message describing what changed.

Branches

A branch is a separate line of work. This project uses a dev branch for course work so the main branch stays untouched.

Pushing to GitHub

git push sends local commits to the remote repository. Work that only exists on my computer cannot be graded or shared.
